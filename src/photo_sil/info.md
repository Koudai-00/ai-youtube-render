## パイプライン (tools/make_photo_figures.py)
1. `npx hyperframes remove-background` (u2net) で切り抜き → alpha>100 マスク
2. MinFilter/MaxFilter(5) でノイズ除去 → bbox クロップ
3. シルエット: potracer でベクター化 (`potrace.Bitmap(~mask)` 反転必須) → currentColor SVG
4. ヒーロー: MedianFilter+彩度/コントラスト強調+10色量子化ポスタライズ+白フチ10px → PNG
- 群衆写真はu2net不適 → 輝度閾値 (lum<55, 上部35%除外) で帯化

## 採用経緯
- 棒人間ピクトグラム (pictogram2) はインパクト不足とのユーザー指摘 (2026-11-20)
- 参考動画(たっくーTV)の人物表現=写真由来のリアルシルエット+ポスタライズ切り抜き
  → 写真をマスク化してトレースすれば同等品質を機械生成できると判断
- 電話を耳に当てるポーズは切り抜きがブロブ化するため不採用 (スマホ操作立ち姿で代替)
- ピクトグラムは小さいアイコン用途 (スタンプ等) に限定して継続使用
